SkillBridge API (1.0.0)

Download OpenAPI specification:

License: MIT

API contract for SkillBridge based on the Week 3 endpoint list. This API provides expert discovery, consultation booking, logistics integration with Maji Website, and delivery tracking.

Experts

Verified expert discovery, profile lookup, availability slots, and reviews

Return verified expert profiles

Authorizations:
bearerAuthNone
query Parameters
estate
string
Example: estate=Westlands
sort
string
Enum: "rating" "proximity"
Example: sort=rating
lat
number <double>
Example: lat=-1.286
lng
number <double>
Example: lng=36.817

Responses

Local development server

http://localhost:3001/api/experts
